# 使用手册

[返回项目首页](../README.md)

## 快速上手

1. 启动程序，在左上角选择游戏；未找到时手动添加包含 `gameinfo.txt` 的游戏内容目录。
2. 程序自动扫描本地模组，也可点击“添加模组”导入单文件 VPK。
3. 点击行内开关启停模组，或勾选后使用底部的批量操作。
4. 点击“启动游戏”，通过 Steam 启动当前游戏。

游戏运行时自动暂停启停和导入操作，搜索、详情与分组整理仍可使用。退出游戏后，程序等待配置保存并自动刷新列表。当前完整支持 **Left 4 Dead 2**，其他已识别的 Source 游戏仅支持只读浏览。

## 列表与详情

- 搜索名称、文件名、作者或标签；通过标签和“启用状态”筛选，点击列头排序。
- 点击模组名称查看详情；点击封面或行内空白区域进行勾选，表头全选仅包含当前筛选结果。
- 灰色文件名表示尚未识别到名称，详情中会提示补全方式。
- 拖动表头分隔线调整列宽，松开鼠标后保存；作者和修改时间列可在“设置 → 列表显示”开启。
- 右键模组可查看详情、定位文件、复制路径或调整分组；右键已勾选的模组时，分组操作作用于全部勾选项。

## 自定义分组

点击左侧“分组”旁的“新建”创建分组。勾选模组后，通过底部“加入分组”添加成员；在分组内可将所选成员移出。

分组右侧开关控制整组，`⋯` 菜单用于重命名或删除。一个模组可以属于多个组，修改其启用状态会同时影响这些组；整组操作包含被筛选隐藏的成员。删除分组或移出成员均保留模组文件。

## 工坊资料

- 在详情获取工坊资料时会补全缺失名称，有效本地名称会保留。
- 打开详情时按需获取工坊文字简介，缓存可离线阅读；获取失败可点击“重试”。
- 点击详情底部的“工坊关联”，粘贴工坊链接或数字 ID 后点击“获取并关联”，也可替换已有的错误关联。
- 使用“在 Steam 中打开”或“浏览器打开”访问原页面。

公开资料无需登录。私有、已移除或受限项目可能无法获取；订阅、下载和更新仍由 Steam 管理。

## 设置与数据

点击顶栏“设置”打开侧栏，在“列表显示”调整显示列或重置列宽，在“数据与维护”重新扫描或打开数据目录。显示设置更改后自动保存，末尾可查看版本和许可信息。

分组、界面设置和工坊关联保存在程序旁的 `data` 目录，备份或迁移时复制整个目录。启用状态直接写入游戏的 `addonlist.txt`。

目前仅支持导入单文件 VPK，不支持分卷导入、冲突检测或加载顺序调整。

## 验证

构建步骤见 [README](../README.md#构建与运行)。找不到着色器编译器时，将 Windows SDK 的 `fxc.exe` 加入 PATH，或用 `GPUI_FXC_PATH` 指定其路径。分发时使用 `target/release/addon-wrench.exe`，并保留 [LICENSE](../LICENSE) 和 [第三方许可](../licenses/GPUI-APACHE-2.0.txt)。

```powershell
cargo test --locked -- --include-ignored
cargo test --locked --no-default-features --lib -- --include-ignored
```

所有测试默认启用，使用独立测试数据。真实游戏联调和 Steam 在线接口实测尚未完成。
